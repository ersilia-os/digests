## 🤖 Models that could join the Hub

### 🎯 Activity prediction

- [Helmy et al., *BMC Bioinformatics*, 2026-07-22](https://doi.org/10.1186/s12859-026-06552-7) 🌍🤖💻 — **Mol2Image: an enhanced DDI prediction framework leveraging drug molecular descriptors.** Open-source activity-prediction model taking SMILES pairs → drug–drug interaction label; released with inference code on GitHub, though the repository carries no licence file (license: unspecified). Plausible Hub addition because it is Egyptian-led, trained on DrugBank (443,046 interactions) plus ChCh-Miner (48,514 DDIs), and the Hub has no DDI endpoint at all. · [code](https://github.com/NourhaanMoHamed/Mol2Image) · 🎯
- [Xiong et al., *IEEE Trans Neural Netw Learn Syst*, 2026-07-24](https://doi.org/10.1109/tnnls.2026.3713190) 🤖💻 — **GoMA-DTA: a Gene Ontology-guided multimodal attention fusion model for drug-target affinity prediction.** Open-source activity-prediction model taking SMILES + target sequence → binding affinity, using GO annotations to recalibrate ESM-2 embeddings; code is public but unlicensed (license: unspecified). Plausible Hub addition because compound–protein interaction models fit the Hub's fixed-target pattern and affinity coverage remains thin. · [code](https://github.com/xa-123955/GoMA-DTA) · 🎯
- [Nasiri et al., *bioRxiv*, 2026-07-27](https://doi.org/10.64898/2026.07.23.740240) 🌍🤖💻 — **B-SMART-Former: an explainable transformer-based deep learning model for predicting drug-drug interactions between biotech and small-molecule drugs.** Open-source activity-prediction model taking SMILES → interaction type against a biotech partner, combining ChemBERTa embeddings with Morgan fingerprints; repository public but unlicensed (license: unspecified). Plausible Hub addition because it is Iranian-led and covers the biotech–small-molecule axis that generic DDI predictors omit. · [code](https://github.com/BioinformaticsIASBS/B-SMART-Former) · 🎯

### 🧪 Property prediction

- [Ding et al., *arXiv*, 2026-07-19](https://arxiv.org/abs/2607.18332) 🤖💻 — **ChemHyperMag: physics-informed magnetic hypergraph learning improves molecular ADMET prediction.** Open-source property-prediction model taking SMILES → multitask ADMET panel, building functional-group hypergraphs from BRICS fragments and Bemis-Murcko scaffolds and encoding non-reversible flow with a Hermitian magnetic Laplacian; released with code under Apache-2.0. Plausible Hub addition because it handles missing labels natively and ADMET multitask predictors are the Hub's third-largest family. · [code](https://github.com/1anj/ChemHyperMag) · 🧪
- [Shen et al., *Anal Chem*, 2026-07-18](https://doi.org/10.1021/acs.analchem.6c03104) 🤖💻 — **ClipMol: a molecular representation learning framework for CCS prediction via SMILES–InChI dual-view chemical language alignment.** Open-source property-prediction model taking SMILES → collision cross-section, using contrastive alignment between SMILES and InChI views; code public but unlicensed (license: unspecified). Plausible Hub addition because CCS supports metabolite and natural-product identification workflows the Hub currently cannot serve. · [code](https://github.com/CIB-MSLab/ClipMol) · 🧪

### 🧩 Featurization

- [Pfizer Open Source, *GitHub*, 2026-07-28](https://github.com/pfizer-opensource/SAND) 🤖💻 — **SAND: Shape Aware Neural Descriptor.** Open-source featurization model taking a 2D molecular graph (from SMILES) → compact embedding that retrieves shape-similar molecules without generating conformers; released with pretrained checkpoints (compressed k=256/m=32 and unquantized) under Apache-2.0. Plausible Hub addition because it is a clean drop-in descriptor with weights already published and no conformer-generation dependency. · 🧩
- [Wedig et al., *arXiv*, 2026-07-22](https://arxiv.org/abs/2607.19977) 🤖💻 — **Rem3Di: learning smooth, chiral 3D molecular descriptors from atomistic foundation models.** Open-source featurization model taking a 3D structure → fixed-length whole-molecule descriptor repurposed from foundation machine-learned interatomic potentials; released with code under Apache-2.0. Plausible Hub addition because it is chirality-aware and smooth in 3D, two properties absent from the Hub's current fingerprint and transformer featurizers. · [code](https://github.com/molsuit/Rem3Di) · 🧩
- [Han et al., *arXiv*, 2026-07-15](https://arxiv.org/abs/2607.20551) 🤖💻 — **SenCos-GEM: SENet-calibrated and law-of-cosines-constrained geometry-enhanced molecular representation for property prediction.** Open-source featurization model taking SMILES with generated 3D geometry → pretrained representation for downstream property tasks, adding explicit physical constraints to reduce force-field geometry noise; code public but unlicensed (license: unspecified). Plausible Hub addition because it targets the catastrophic-forgetting failure mode that limits reuse of 3D pretrained encoders. · [code](https://github.com/zhaoqi106/SenCos-GEM) · 🧩

### 🎨 Generative

- [Chen et al., *J Chem Inf Model*, 2026-07-20](https://doi.org/10.1021/acs.jcim.6c01342) 🤖💻 — **MolT5-Linker: a transformer-based sequence- and putative site-guided generative framework for antibody-drug conjugate linkers.** Open-source generative model emitting SMILES linkers conditioned on sequence and putative conjugation site; code public but unlicensed (license: unspecified). Plausible Hub addition because linker generation is a well-scoped generative task and the Hub's generative bucket is its smallest at 5%. · [code](https://github.com/yjchen54/MolT5-Linker) · 🎨

## AI/ML methods for drug discovery

- [Zhang et al., *Nature Machine Intelligence*, 2026-06-10](https://doi.org/10.1038/s42256-026-01257-1) ⭐ — **Reusability report: assessment of reproducibility and applicability to external datasets for RXNGraphormer.** An independent reproduction attempt on a reaction-graph transformer, reporting where external-dataset performance degrades; the template for the kind of scrutiny every Hub incorporation candidate should survive before it ships.
- [Yang & Deng, *J Chem Inf Model*, 2026-07-20](https://doi.org/10.1021/acs.jcim.6c01209) — **Self-supervised learning for molecular property prediction: methods, multimodal insights, and benchmark comparisons.** A survey plus head-to-head benchmark of SSL pretraining strategies for molecular property prediction, useful as a shortlist when choosing which featurizer families to prioritise for the Hub.
- [Jimenez Siegert et al., *Communications Chemistry*, 2026-07-21](https://doi.org/10.1038/s42004-026-02122-3) — **Rapid and energy-efficient ultra-large library screening for drug discovery on a SpiNNaker2 neuromorphic chip.** Screens 19 billion Enamine REAL compounds with feed-forward networks on 2D descriptors, benchmarked against GPU baselines on both speed and energy. (Infra: 152-core neuromorphic hardware — not containerisable, but the energy argument matters for low-resource deployment.)
- [Liu et al., *Communications Chemistry*, 2026-07-18](https://doi.org/10.1038/s42004-026-02115-2) — **Integrating chemical priors and physical laws to mitigate hallucinations in structure-based drug design.** Adds chemistry and physics constraints to structure-based generators to suppress invalid or unphysical outputs. (Input: protein pocket; license: CC-BY-NC-ND — fails Hub redistribution on both counts.)
- [Gou et al., *Communications Chemistry*, 2026-07-06](https://doi.org/10.1038/s42004-026-02113-4) — **Molecular ground-state conformation prediction based on the Mamba state space model.** A state-space alternative to transformer conformer prediction, taking molecular graphs to ground-state 3D geometry. (License: CC-BY-NC-ND — otherwise this would clear the Hub checklist.)
- [Rossen & Grisoni, *chemRxiv*, 2026-07-27](https://chemrxiv.org/doi/abs/10.26434/chemrxiv.15006508/v1) 💻 — **MolForge: building reproducible molecular datasets at speed and scale.** A configurable curation and conformer-generation pipeline that makes dataset construction choices explicit and replayable, released under MIT. Directly relevant to how Hub training sets are documented and regenerated. · [code](https://github.com/molML/molforge)
- [Varghese et al., *bioRxiv*, 2026-07-23](https://doi.org/10.64898/2026.07.20.739289) — **CHIMIYA-1: an autoselection foundation model for ADMET property prediction, rigorously benchmarked against the Therapeutics Data Commons ADMET group.** Reports strong results across the 22-endpoint TDC ADMET benchmark under scaffold splits. (License: proprietary model — a benchmark reference point rather than an incorporation candidate.)
- [Qin et al., *arXiv*, 2026-07-21](https://arxiv.org/abs/2607.19237) — **DBMol: design of high-affinity, target-specific small molecules through structure prediction models.** Uses AlphaFold-3 and Boltz-2 as differentiable optimisation signals to design ligands without reference compounds. (Input: protein pocket — Hub-eligible once protein-input support lands.)
- [Hong et al., *arXiv*, 2026-07-20](https://arxiv.org/abs/2607.17601) — **Trustworthy protein-ligand binding affinity prediction via reliability-aware multi-engine fusion.** RELIABLE-BA models each docking engine as an evidential expert and decomposes uncertainty, so disagreement between engines becomes an interpretable confidence signal rather than noise. (Infra: requires multiple docking engines at inference.)
- [Tan et al., *chemRxiv*, 2026-07-22](https://chemrxiv.org/doi/full/10.26434/chemrxiv.15006418/v1) — **Quantifying ternary complex stability through binding free energy calculations in the geometric route.** An umbrella-sampling protocol that predicts ternary-complex binding free energies well enough to rank degraders, from the Ciulli and Michel groups. Direct methodological input to the molecular-glue work under the BBVA Prisms *glueAI* track.
- [Le et al., *bioRxiv*, 2026-07-24](https://doi.org/10.64898/2026.07.24.740457) 🌍 — **Rank-resolved multi-engine docking and Optuna-optimized re-ranking with ProDock for virtual screening.** Vietnamese-led extension of ProDock combining GNINA local docking with DiffDock global docking plus pose-level descriptors to cut virtual-screening false positives. (Input: protein target — a screening workflow, not a Hub model.)
- [Xu et al., *bioRxiv*, 2026-07-25](https://doi.org/10.64898/2026.07.21.739736) — **Phenotype-driven de novo molecular design from gene expression signatures.** Generates molecules conditioned on transcriptomic disease signatures rather than a named target, addressing the loss of phenotypic information during generation. (Input: gene expression — outside the current Hub small-molecule-input surface.)
- [Gankin & Beltrao, *bioRxiv*, 2026-07-20](https://doi.org/10.64898/2026.07.15.738681) — **Leveraging multiplicity in biologically informed neural networks to uncover disease heterogeneity.** Shows that biologically informed networks trained identically on 500,000 UK Biobank samples reach equal accuracy while prioritising different genes, and that this instability is itself informative. A caution worth carrying into any interpretability claim made about Hub models.
- [Liu & Liu, *Int J Mol Sci*, 2026-06-30](https://doi.org/10.3390/ijms27135916) — **Evaluating AI-generated molecules for drug discovery: from generic metrics to translational readiness.** Proposes a six-stage, failure-aware evaluation framework spanning validity, medicinal-chemistry feasibility, novelty in context, and translational readiness — a more honest scoring rubric than the validity-uniqueness-novelty triad still used by most generative papers.

## Antibiotic and antimicrobial discovery

- [Mauša & Kalafatovic, *Nature Machine Intelligence*, 2026-06-25](https://doi.org/10.1038/s42256-026-01258-0) ⭐ — **Data-driven surrogates of rational design enable antimicrobial peptide optimization.** Learns surrogate models of expert design heuristics to steer AMP optimisation, reducing reliance on hand-built rules. (Input: peptide sequence — outside the Hub's small-molecule surface, but the surrogate-of-heuristics framing transfers to small-molecule AMR series.)
- [van der Hilst, *Nature Biomedical Engineering*, 2026-07-17](https://doi.org/10.1038/s41551-026-01761-0) ⭐ — **Outracing antibiotic resistance with deep learning.** A short perspective on where deep learning is and is not shortening the antibacterial pipeline; useful framing for positioning Ersilia's AMR work against the broader field.
- [Levy & Hergenrother, *ACS Infect Dis*, 2026-07-18](https://doi.org/10.1021/acsinfecdis.6c00421) — **Random forest modeling to predict small molecule accumulation in Gram-negative bacteria.** A detailed protocol for using interpretable random forests to link physicochemical descriptors to permeation, efflux evasion and accumulation in *E. coli* and *P. aeruginosa*. No model is released, but the descriptor choices and accumulation guidelines map directly onto the Grand Challenges Gram-negative AMR (*E-AMR-CC*) track.
- [Aledavood et al., *Communications Chemistry*, 2026-07-17](https://doi.org/10.1038/s42004-026-02138-9) — **AI-assisted fragment-based drug discovery of SARS-CoV-2 macrodomain binders validated by NMR and X-ray crystallography.** A rare end-to-end case where AI-proposed fragments were confirmed by two orthogonal structural methods — the experimental-validation standard that computational hit-finding claims should be held to.
- [Kazia et al., *ACS Med Chem Lett*, 2026-07-19](https://doi.org/10.1021/acsmedchemlett.6c00268) — **Peptidic phosphonates as irreversible covalent inhibitors of *Plasmodium falciparum* serine protease PfSUB1.** Covalent inhibitors of an essential egress protease, extending the antimalarial target set beyond the kinase and MEP-pathway families that dominate current Hub antimalarial coverage.
- [Rankine-Wilson & Av-Gay, *ACS Infect Dis*, 2026-07-01](https://doi.org/10.1021/acsinfecdis.6c00093) — **Comparative phenotypic screening identifies protein synthesis inhibitors as compounds that enhance early acidification of *Mycobacterium tuberculosis* in macrophages.** An intracellular phenotypic readout rather than a whole-cell MIC, offering a host-context TB endpoint that differs from the axenic assays behind most antitubercular models.
- [Yurtseven et al., *Bioinformatics*, 2026-07-22](https://doi.org/10.1093/bioinformatics/btag545) 💻 — **ALPAR: automated learning pipeline for antimicrobial resistance.** An end-to-end open pipeline from raw genomes to AMR phenotype models, aimed squarely at lowering the entry barrier for newcomers. (Input: bacterial genome — complements rather than competes with the Hub's compound-side models.)
- [Gerst et al., *bioRxiv*, 2026-07-23](https://doi.org/10.64898/2026.07.22.739984) 💻 — **J-AST: a web-based analysis platform for antimicrobial susceptibility testing.** Free open-source quantification of disk-diffusion and Etest assays including tolerance, filling a genuine gap in open AST tooling for labs without commercial readers.

## AI agents and foundation models for science

- [Chen et al., *Nature Machine Intelligence*, 2026-07-01](https://doi.org/10.1038/s42256-026-01261-5) ⭐ — **An agentic artificially intelligent X-ray scientist.** An LLM agent using the Model Context Protocol plans, executes, analyses and iterates experiments on a six-circle diffractometer setup — one of the first credible closed-loop demonstrations at a large-facility instrument, and a concrete blueprint for MCP-driven autonomous experimentation.
- [Kim et al., *Nature Machine Intelligence*, 2026-07-24](https://doi.org/10.1038/s42256-026-01268-y) ⭐ — **Capable language models can outgrow the benefits of collaboration.** Finds that multi-agent collaboration gains shrink and can invert as single-model capability rises — a direct caution against defaulting to multi-agent architectures for scientific reasoning tasks.
- [Goh et al., *npj Digital Medicine*, 2026-05-25](https://doi.org/10.1038/s41746-026-02777-1) — **Rethinking bioinformatics expertise in the era of artificial intelligence.** Argues AI is an accelerant whose value depends on expert curation, interpretation and governance rather than a replacement for computational biologists — relevant to how Ersilia frames capacity-building alongside automation.

## Global health and open science

- [Awuah et al., *Mol Genet Genomics*, 2026-07-22](https://doi.org/10.1007/s00438-026-02492-2) 🌍 — **The use of artificial intelligence in advancing molecular biology in Africa: a narrative review.** A fourteen-author review led from the University of Cape Coast mapping current AI adoption in African molecular biology alongside infrastructure, data and training constraints. Directly relevant context for the GC-ADDA and H3D-facing side of Ersilia's work, and notable for being African-led rather than about Africa.
- [World Health Organization, 2026](https://www.who.int/news-room/fact-sheets/detail/antimicrobial-resistance) — **Antimicrobial resistance fact sheet.** The refreshed WHO baseline on AMR burden and priorities; the reference point to cite when framing Ersilia's AMR portfolio for funders and policy audiences.
