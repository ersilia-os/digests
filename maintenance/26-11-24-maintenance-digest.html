How these numbers are derived

Population. Every figure divides by the 243 models the hub search returns with status Ready. Archived and in-progress models are excluded: they are not served, so a missing artefact for them is not a gap. Artefacts we still store for non-Ready models are counted separately and never folded into a coverage percentage.

Precalculation coverage. A model is complete when it has a stored prediction for all 1,355,109 molecules in the isaura reference collection — the size of that collection is the definition of “full”. Where a model is stored at several versions, the version with the most molecules is the one measured, since the question is whether the predictions exist at all.

Latest version. The latest release is the highest semantic-version tag in each model's GitHub releases. isaura stores versions by major, so the latest version counts as stored only when <model_id>/v<major> holds all 1,355,109 molecules.

Singularity images. Objects in s3://models-sif named <model_id>_v<major>.sif, joined to the same population. An image is up to date when it matches the major of the model's latest GitHub release and was uploaded on or after the release that began the latest minor line (its .0; patch releases do not rebuild images). 287 images cover 237 models.

Maintenance. Read from the published reports in ersilia-os/ersilia-maintenance, not recomputed here. The monthly series changed field names part-way through, so both namings are read; an em dash means a month does not record that figure, which is not the same as a zero.
